# Испанский — тренажёр слов и фраз (Этап 1: скелет)

Это первая, "черновая" версия — проверяем, что механика (интервалы повторения,
проверка ответов, статусы слов) работает и ощущается правильно. Красивого
интерфейса, уровней/тем в UI, уведомлений, синхронизации с телефоном тут
**намеренно нет** — это следующие этапы.

## Как запустить

Нужен только Python 3 (ничего дополнительно ставить не надо — tkinter и
sqlite3 идут в комплекте со стандартной установкой Python на Windows/Mac/Linux).

```
python main.py
```

При первом запуске приложение само создаст базу данных `progress.db` рядом
с `main.py` и загрузит туда колоду слов (`data/words.csv`, 3738 слов) и фраз
(`data/phrases.csv`). При повторных запусках уже загруженные слова не
дублируются, а твой прогресс (статусы, интервалы) сохраняется в `progress.db`.

## Что уже работает

- **Режим слов**: показывает слово либо на русском (переведи на испанский),
  либо на испанском (переведи на русский) — направление выбирается случайно,
  кроме режима проверки (см. ниже). Опечатки допускаются, показывается
  процент совпадения.
- **Режим фраз**: фраза на русском, 4 варианта перевода на испанском.
  Внутри — **временный** набор из 36 фраз, который я сочинила сама, чтобы
  механику было на чём проверить. Когда пришлёшь свой список фраз с
  вариантами — заменим `data/phrases.csv` на него.
- **5 статусов слова**: неизвестно → начато → в процессе → требует проверки → изучено.
- **Интервалы**: 7 минут → 1 час → 1 день → 3 дня → неделя → месяц, дальше —
  адаптивный рост (как в Anki). Любая ошибка откатывает слово на самый
  первый интервал.
- **"Изучено"** — только после 4 верных ответов ПОДРЯД именно в режиме
  проверки (RU→ES, когда слово уже прошло весь интервальный цикл). Ошибка
  в этом режиме сбрасывает счётчик и возвращает слово в обычный цикл.
- **Дневной лимит новых слов** — настраивается в меню (5-20). После лимита
  новые слова не показываются, но уже начатые слова продолжают появляться
  по своему расписанию.

## Решения, которые я приняла сама (уточни, если что-то не так)

Часть деталей в исходном ТЗ не была прописана до последней запятой — вот
где я додумала сама, по аналогии с Anki:

1. **Порог "правильно/неправильно" при опечатках** — совпадение ≥85% (по
   алгоритму сравнения строк) считается верным ответом. Можно поменять
   порог в `app/matching.py` (`CORRECT_THRESHOLD`).
2. **После цикла интервалов (получил статус "требует проверки")** —
   слово даётся на проверку сразу, а между попытками (если раньше не
   хватило 4 подряд) — интервал в месяц, а не что-то более частое. Если
   хочешь, чтобы "довыучивание" шло быстрее — скажи, поменяю.
3. **Ошибка в режиме "требует проверки"** — сбрасывает не только счётчик
   4-х попыток, но и весь интервал (слово возвращается в "в процессе" с
   самого начала). Это самый строгий вариант трактовки твоего "слово
   откатывается назад, пока не закрепится".

## Чего здесь ещё нет (следующие этапы)

Телефон/PWA, синхронизация через Firebase, уведомления, тест-плейсмент,
шкалы по уровням/темам, режим времён глаголов, финальный дизайн (тёмно-синий
экран, иконки) — всё по плану, но не в этом скелете.

## Структура проекта

```
main.py              — запуск приложения
app/db.py             — схема базы данных (SQLite)
app/importer.py       — загрузка CSV в базу
app/deck.py            — выбор следующего слова/фразы, дневной лимит
app/srs.py             — логика интервалов повторения и статусов
app/matching.py        — проверка ответа (опечатки, ударения)
app/gui/               — экраны интерфейса (tkinter)
data/words.csv          — колода слов (3738, из personal-заметок + proespanol.ru)
data/phrases.csv        — колода фраз (пока временная, 36 штук)
tests/test_smoke.py     — быстрая проверка что ядро работает: `python tests/test_smoke.py`
```

⚠️ **Про будущую публикацию на GitHub**: `data/words.csv` частично собран с
proespanol.ru (без лицензии на переиспользование) — прежде чем выкладывать
репозиторий в открытый доступ, этот файл (и `data/phrases.csv`, если в него
попадут чужие фразы) нужно исключить через `.gitignore` или заменить на
пример из нескольких слов. Пока это на будущее, сейчас файл нужен для
локальной работы.
